# Identidad de Walter Moya

Monograma geométrico «WM» en blanco cálido y menta sobre verde profundo. Las iniciales comparten un corte diagonal y trazos amplios para mantener su lectura en tamaños pequeños.

Creado con la herramienta integrada `imagegen`. Los archivos web se obtuvieron del PNG seleccionado mediante cambio de tamaño y conversión de formato, sin modificar el diseño.

| Archivo | Uso |
| --- | --- |
| `walter-moya-logo.png` | Original seleccionado, 1254 × 1254 px |
| `walter-moya-icon-192.png` | Versión de 192 px para la imagen de redes |
| `apple-touch-icon.png` | Icono de 180 px para accesos directos en iOS |
| `../../app/favicon.ico` | Icono de pestaña, con tamaños de 16, 32, 48 y 64 px |

La cabecera usa Next/Image para servir una versión optimizada. La imagen Open Graph incorpora el mismo símbolo. Los iconos se comparten entre español e inglés y la dirección declarada del favicon incluye una versión para renovar la caché.
